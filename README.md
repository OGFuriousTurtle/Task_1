# 🎤 India's Got Latent — Chatbot Act

## Contestant Profile

**Act name:** The Persona Machine
**Category:** Conversational AI, live and unscripted
**Why it'll impress the panel:** Most chatbots on this stage will say "Hi, how can I help you?" and stay there all night. This one doesn't. Pick an act: a roast comic, a Shakespearean tragedian, an emoji-only translator, or an average BITSian running on zero sleep telling you 'lite lo'. And it commits to that bit for the whole performance. Ask it something three questions later that calls back to what you said earlier, and it'll remember. No re-running the file between questions. No script.
